# AI Signal Daily

Открытое русскоязычное AI-издание на Next.js 16. Главная страница показывает последний выпуск, архив хранит предыдущие дни, защищённый editorial API принимает ручные публикации, а ежедневный Vercel Cron готовит новый выпуск через AI Gateway с веб-поиском и проверкой источников.

## Локальный запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

Создайте PostgreSQL. `npm run build` идемпотентно применяет `db/migrations/001_initial.sql`, если задан `DATABASE_URL`. При локальном запуске без базы приложение показывает явно помеченный вымышленный образец. Production без базы показывает пустое состояние до первой публикации. Читательские страницы открыты без регистрации и входа; запись разрешена только через editorial API и авторизованный cron.

## Переменные окружения

- `DATABASE_URL`
- `EDITORIAL_API_SECRET`
- `CRON_SECRET`
- `AI_GATEWAY_MODEL` — необязательная конфигурация; по умолчанию используется проверенная модель из кода

Секреты задаются в Vercel, не в Git. `NEXT_PUBLIC_*` для привилегированных значений не используется.

## Проверки

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

В реальном выпуске применяйте только проверенные статьи. Подписание X-публикации полем `verified: true` — утверждение редактора после ручной проверки URL и содержания; сервер дополнительно проверяет домен и структуру ссылки.

## Ежедневная публикация

Vercel вызывает `/api/cron/publish` ежедневно в 07:00 UTC. Маршрут доступен только с `CRON_SECRET`, сначала проверяет наличие сегодняшнего выпуска, затем:

1. собирает публикации последних суток из фиксированного списка официальных RSS/Atom-источников;
2. собирает первичные и corroborating sources;
3. пишет русскоязычный выпуск по редакционному контракту;
4. проверяет, что каждый опубликованный URL действительно пришёл из официального feed;
5. повторно валидирует payload через Zod и сохраняет его одной PostgreSQL-транзакцией.

Если поиск, генерация или проверка качества завершились ошибкой, новый выпуск не записывается, а сайт продолжает показывать последний успешный. Ручная публикация через editorial API остаётся доступной для исправлений и редакционных выпусков.
