# Безопасность

- Читательские маршруты и поиск публичны и выполняют только чтение.
- Editorial API проверяет отдельный серверный secret через constant-time comparison.
- Cron API использует отдельный `CRON_SECRET`; оба секрета существуют только в Vercel Environment Variables.
- Zod запрещает неизвестные категории, короткие статьи, локальные и не-HTTP источники, непроверенные X URL.
- Автоматический редактор публикует только URL, фактически возвращённые серверным веб-поиском; X в автоматическом режиме отключён.
- SQL-параметры передаются через tagged templates; выпуск сохраняется транзакционно.
- `robots.txt` запрещает обход всего сайта, metadata выставляет noindex/nofollow/nosnippet.
- Ответы также получают `X-Robots-Tag`, `Referrer-Policy: no-referrer`, `nosniff` и запрет на встраивание во frame.
- Секреты исключены `.gitignore`; `.env.example` содержит только имена переменных.
- Ошибки API не возвращают SQL или значения секретов. Привилегированных `NEXT_PUBLIC_*` нет.

Перед production: поставить длинные случайные `EDITORIAL_API_SECRET` и `CRON_SECRET`, ограничить доступ к базе, оставить Vercel Deployment Protection только для preview при необходимости и регулярно ротировать секреты. `AI_GATEWAY_MODEL` не является секретом. AI Gateway в Vercel использует автоматически выдаваемый короткоживущий OIDC-токен, поэтому ключ провайдера в проекте не нужен.
